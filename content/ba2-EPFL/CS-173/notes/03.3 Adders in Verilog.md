> [!Algorithm] Create a circuit
> 1. Name your circuit
> 2. Label all inputs and outputs
> 3. Label all logic gates
> 4. Label wires

Example :
```Verilog
module fulladd (a, b, c_in ,s ,c_out);
	input a, b, c_in;
	output s, c_out;
	
	wire w1, w2, w3;
	
	// Note : we can ommit the gate names for a simpler looking circuit
	and And1(w1, a, b);
	and And2(w2, a, c_in);
	and And3(w3, b, c_in);
	
	or Or1(c_out, w1, w2, w3);
	xor Xor1(s, a, b, c_in);
endmodule
```
